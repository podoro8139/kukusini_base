# 04 サイト設計

出典：BASE_HTML編集でできること.md、方針のご提案.pdf

## BASE（HTML編集 App）の制約 ― 要点
- テンプレートは **HTML 1ファイル**。`{block:ページ名}` でページを出し分け
- **ページは増やせない**（ページ追加 App は HTML編集テーマでは使えない）
- カート・購入手続き・マイページは触れない
- 詳細ページから別商品を直接カートに入れられない（おすすめはリンクのみ）
- お問い合わせフォームの項目は変えられない（と思われる）
- サーバー処理は作れない（絞り込み検索 → カテゴリへのリンクで代用）

| ページ | ブロック | 自由度 | 使い方 |
|---|---|---|---|
| トップ | `{block:IndexPage}` | ◎ | **サイトの中身の大半をここに縦に並べる** |
| カテゴリ／検索 | `{block:IndexPageCategory}` / `{block:IndexPageSearch}` | ○ | トップと枠を共有。表示切替のみ |
| 商品詳細 | `{block:ItemPage}` | ◎ | 文章・画像は管理画面から。JSで「一緒にどうぞ」を出し分け可 |
| About | `{block:AboutPage}` | ○ | 本文は管理画面の「ショップ紹介」 |
| お問い合わせ | `{block:ContactPage}` | △ | フォームはBASEが出す |
| 特商法／プライバシー／ブログ | 共通枠＋`{PageContents}` | × | 個別デザインほぼ不可 |

### 実装の注意
- **必須タグを消すと保存できない**：`{BackgroundTag}`（実際にエラー）、`{BASEMenuTag}`、`{PageContents}`、`{IllegalReportTag}` など
- CSS は必ず `;` で終える（`{display:none;}`）。JS オブジェクトは `{ key: value }` とスペースを入れる（BASEタグとの誤認防止）
- CSS はテンプレート内 `<style>` にまとめる。画像はファイルアップローダーのURLを使う
- URL：商品 `https://shop.kukusini.com/items/{商品ID}`、カテゴリ `https://kukusini.base.shop/categories/{カテゴリID}`

## ページ構成案

### トップ（ワイヤー v0.2・11/24 時点）
1. **ファーストビュー** ― 「うちの子のために、素材からつくり方まで。」＋バナー2枚（①初回限定 3種類お試しセット → セットの商品ページ ②選び方 → 下の3グループ）
2. **想い** ― 「ペットではなく、家族だから。」＋キーワード3つ（淡路どり・朝の鶏肉・手切り）→ Aboutへ
3. **商品一覧** ― 9種（`{block:Items}`）、大容量500gへの入口
4. **選び方** ― やわらかめ／噛みごたえ／ごはんにかける の3グループ（各商品ページへリンク）。9種類の比較表はブログ記事へ
5. **お客様の声**
6. **FAQ**（`#faq`）
7. 卸・メディアの方へ（控えめに。お問い合わせへ誘導）

提案書の構成から変えた点：「はじめての方へ」はバナー①に置き換えて削除、「素材・製法へのこだわり」はAboutへ移動。
独立ページが作れない「淡路どりのこと」はAbout、「比較表」はブログ、「FAQ」はトップで受ける。

### 商品詳細
- 共通の枠に「硬さ・風味・おすすめ犬種」「保存方法」「注意事項」を表示
- 関連商品リンク（例：ささみ → むね・ふりかけ）

### 導線
| 対象 | 導線 |
|---|---|
| 初回 | ささみ推し＋お試し／食べ比べセット、送料・初回キャンペーン（要検討） |
| リピーター | 60g・500g大容量を見つけやすく |
| 卸業者 | 卸対応の案内・取扱商品・問い合わせ窓口（価格表・最低ロットの公開可否は未決） |
| メディア | ブランド概要・商品情報・問い合わせ先 |
| 問い合わせの振り分け | フォームが変えられないため「本文冒頭に【卸】【取材】と記入」と案内 |
