# 02 ブランド・淡路どり

出典：ヒアリングシート 01・02・06。**掲載可否はすべて「要確認」**。サイトに載せる文章は南さんの最終確認を通すこと。

## ブランドの想い
- 理念のイメージ：**「家族の幸せが私の幸せ」**（祖父母が孫に買ってあげて、孫が喜ぶと祖父母も嬉しい、という感覚）
- 目指す姿：**「愛犬にあげる鶏肉なら kukusini を選べば間違いない」**。かつては「淡路島を代表するペットフード」、今は「鶏といえば kukusini」
- 根っこ：自分の子どもにもあげられる素材で、「とりあえず食べられる」ではなく **「食べて豊かになるもの」** を
- 始まり：淡路フーズの鶏肉で何かできないかと試作 → 自分の犬に自信を持って与えられるものを → コロナ禍でペットを飼う人が増え、本格化
- 今後の構想：ギフトセット、レトルト、小分け冷凍の調理補助食品、宅配冷凍弁当

## 製造のこだわり
| こだわり | 内容 |
|---|---|
| 朝引き | 当日の朝に処理された鶏肉を使用（肉専門店は翌日、スーパーは翌々日に並ぶのが一般的）→ 人が食べるより新鮮 |
| 生肉 | 冷凍すると解凍時のドリップで旨味が抜けるため、冷凍肉を使わない |
| 手切り | 生肉は柔らかく機械で薄く切れないため、手で割れる薄さに全て人の手でカット |
| 無添加 | 添加物不使用。鶏肉以外は一切使っていない |
| 工程 | 洗浄 → カット → 乾燥 → 検品 → 梱包 |
| 衛生 | 鶏肉の処理工場は HACCP 取得済み／製造者は食鳥処理衛生管理者の資格あり |

## 淡路どり
- 定義：**淡路島で育ち、淡路島で処理された鶏**。品種はブロイラー
- 飼育：ウインドレス鶏舎で平飼い／通常より **2〜3日長く** 飼育 → 身が大きくコクがある
- 飼料：淡路どり用に特別配合、成長過程ごとに分けて給餌
- 製法：**外はぎ方式**（手さばきに近い）。一般的な中抜き方式（機械式）と違い、内臓面が水にさらされずドリップが少ない
- 名称：運営主体なし。一般名称のため商標は取れなかった

- ⚠️ 要確認：鶏・淡路フーズに関するもの全般（商品・ロゴなど自社のものはOK）
- ❌ 避ける表現：**「地鶏」**（淡路どりは地鶏ではない）
- ❌ 祖父のお名前は掲載不可
- 「無添加」「朝引き」は表現OK（南さん回答 2026/11/25）。「唯一」は根拠を確認してから
