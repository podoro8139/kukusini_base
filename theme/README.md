# BASE 用テンプレート（試作 v1）

| ファイル | 中身 |
|---|---|
| `current.html` | **いま公開中のテンプレート（バックアップ）**。元に戻すときはこれを貼る |
| `kukusini-v1.template.html` | 新デザインのテンプレート本体（画像URLなどは `__IMG_LOGO__` のような仮の文字のまま） |
| `config.json` | 画像URL・カテゴリURL・お試しセットのURL・サイズ違いの商品ID |
| `build.py` | `config.json` を差し込んで `dist/kukusini-v1.html` を作る。あわせて見本データ入りのプレビューも作る |
| `dist/kukusini-v1.html` | **BASE の HTML編集 App に貼るファイル** |
| `base-css/` | いまのテーマの CSS（プレビュー用のコピー） |

```bash
python3 wireframes/build.py   # 資料サイトとテンプレートのプレビューをまとめて作る
```

## BASE に入れるまでの手順

1. **バックアップ**：BASE の HTML編集 App で、いまのテンプレートを全部コピーして保存（`current.html` と同じ中身のはず）
2. **画像を上げる**：BASE の「ファイルアップローダー」に `wireframes/mock/img/` の画像を上げ、表示された URL を `config.json` の `images` に貼る
   - LOGO=logo.png / LINEUP=lineup.jpg / SASAMI=sasami.jpg / BREAK=break.jpg / HANDCUT=handcut.jpg / TRAY=tray.jpg / AWAJI=awaji.jpg / CHEW=chew.jpg
3. **カテゴリを作る**：管理画面で「やわらかめ／噛みごたえ／ごはんにかける／大容量500g／お試しセット」を作り、各カテゴリページの URL を `config.json` の `categories` に貼る（空欄なら「商品一覧」に飛ぶ）
4. **お試しセット・ブログ**：商品ページとブログ記事ができたら `urls` に貼る（空欄なら「商品一覧」に飛ぶ）
5. **サイズ違い**：同じ商品の 35g／60g／500g の商品ID（URL の `/items/123456` の数字）を `sizes` に書く。書いた商品だけ「ほかのサイズ」ボタンが出る
6. `python3 theme/build.py` を実行 → `dist/kukusini-v1.html` を HTML編集 App に貼り、**プレビューで確認してから保存**

## 追加の商品説明（商品ごとに南さんが入れる）

いまの追加の商品説明 App は「見出し＋説明」の組で入れる形。新テンプレートではこれを**表**として見せる。
9商品とも次の順で入れる。

| 見出し | 説明の例（ささみ） |
|---|---|
| かたさ | やわらかめ（手でさくっと割れる） |
| 香り | 強め |
| おすすめ | 全犬種。ベビーからシニアまで |
| 使い方 | おやつ・ごほうびに。フードのトッピングに。水でふやかせばシニアの子にも。 |
| 与えるときの注意 | （骨入り・丸のみ注意の商品だけ） |
| 原材料 | 鶏ささみ（淡路どり） |
| 内容量 | 60g |
| 保存方法 | （確認中） |
| 賞味期限 | （確認中） |

文字のない画像のパーツは、これまでどおり「淡路どり・素材や製法へのこだわりを見る」の折りたたみに自動で集まる。

## 本番の前に確かめること

- [ ] プレビューで、購入フォーム（数量・カートボタン）の見た目と動き
- [ ] 追加の商品説明が表になっているか（実際の出力の形が見本と違えば CSS を調整）
- [ ] スマホでメニューが開くか
- [ ] カテゴリページ・検索結果で商品一覧だけが出るか、下までスクロールで続きが読み込まれるか
- [ ] お問い合わせ・特商法・プライバシーのページの見た目
- [ ] 商品ラベル（やわらかめ等）が商品名から正しく付いているか

## いまのテンプレートから変えたこと

- 見た目の部分はすべて新しく（クラス名は `kk-` で始まる）。BASE が出す部分（購入フォーム・お問い合わせ・特商法）のために既存の CSS は読み込んだまま
- トップの商品一覧は 8 件まで表示し、「すべての商品を見る」でカテゴリへ。無限スクロールはカテゴリ・検索ページだけ
  （いまのテンプレートは読み込み先の `#mainContent` がトップに無く、無限スクロールが動いていなかった）
- About は `{block:AboutPage}` に本文を直接書き、管理画面の「ショップ紹介」は下の「お買い物について」に表示
- 使っていなかった Facebook / Twitter の読み込み、古いメイン画像スライダーを外した
- BASE の必須タグ（`{BackgroundTag}` `{BASEMenuTag}` `{PageContents}` `{IllegalReportTag}` など）はすべて残している
