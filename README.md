# kukusini_base

kukusini（淡路どりの犬用ジャーキー）の **BASE ECサイトリニューアル** 用リポジトリ。
Google Drive の共有フォルダにある資料（提案書・ヒアリングシート・ガントチャート・BASE調査メモ・写真）を、作業に使える形に整理したもの。

- 公開目標：**2026/12/23**（スマホ優先）
- ショップ：BASE（`shop.kukusini.com`）／HTML編集 App のカスタムテーマ
- マルシェ初出店：12/20（仮）
- 担当：谷（制作）／南さん（kukusini 側・確認者）

> 原本は Drive。ここは「整理・作業用」。数字や表現を変えるときは Drive 側の原本・南さんの確認を優先する。
