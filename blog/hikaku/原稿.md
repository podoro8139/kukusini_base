# ブログ記事：商品比較（全9種の選び方）

トップの「選び方」にある **「詳しい選び方・比較表」ボタンのリンク先**になる記事。
公開したら記事の URL を `theme/config.json` の `urls`（`__URL_BLOG_GUIDE__`）に貼る。

## BASE での作り方

BASE のブログには表を入れる機能がないので、**比較表は画像にして貼る**。

| 原稿の印 | ブログ編集でやること |
|---|---|
| 【見出し】 | 文字を選んで **h** ボタン |
| 【画像】 | **画像**ボタン → `blog/hikaku/img/` の PNG を選ぶ（10〜18 は商品ごとの小さい画像） |
| 【リンク】 | ▶の前の文字を貼って選び、**リンク**ボタン → ▶のあとのURLを入れる（▶とURLは本文に残さない）。リンク先は60g（きも・砂肝は35g） |
| それ以外 | そのまま貼る |

- 画像は `node blog/hikaku/build.mjs` で作り直せる。価格や名前が変わったら `build.mjs` の `ITEMS` を直して再実行 → 貼り直す
- 「記事を固定する」はチェックしない（トップの「お知らせ」欄に出るのは固定記事だけなので、お知らせ用に空けておく）

### 南さんに確認すること
- [ ] 表示名（砂肝／軟骨入りセセリ／鶏足／鶏頭）をこの名前で出してよいか ※サイトの「選び方」と同じ名前にしている
- [ ] かたさ・香りの☆を、そのまま「作り手の実感」として載せてよいか
- [ ] 手羽先・砂肝・セセリの注意書きの言い方
- [ ] ネック2種（サイコロ／ロング）と鶏頭の扱い ※決まったら build.mjs の ITEMS を直して画像を作り直す
- 価格は画像に入れていない（リンク先の商品ページで見られる。値上げのたびに画像を作り直さずに済む）
- 商品ごとの画像の写真は、ショップの商品ページのメイン写真（`blog/hikaku/photo/`）。写真を変えたら差し替えて `build.mjs` を再実行
