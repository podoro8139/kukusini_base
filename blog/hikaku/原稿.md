# ブログ記事：商品比較（全9種の選び方）

トップの「選び方」にある **「詳しい選び方・比較表」ボタンのリンク先**になる記事。
公開したら記事の URL を `theme/config.json` の `urls`（`__URL_BLOG_GUIDE__`）に貼る。

## BASE での作り方

BASE のブログには表を入れる機能がないので、**比較表は画像にして貼る**。

| 原稿の印 | ブログ編集でやること |
|---|---|
| 【見出し】 | 文字を選んで **h** ボタン |
| 【画像】 | **画像**ボタン → `blog/hikaku/img/` の PNG を選ぶ（10〜18 は商品ごとの小さい画像） |
| 【商品】 | **テント**のボタン → その商品を選ぶ（商品カードが入る） |
| それ以外 | そのまま貼る |

- 画像は `node blog/hikaku/build.mjs` で作り直せる。価格や名前が変わったら `build.mjs` の `ITEMS` を直して再実行 → 貼り直す
- 「記事を固定する」はチェックしない（トップの「お知らせ」欄に出るのは固定記事だけなので、お知らせ用に空けておく）

### 南さんに確認すること
- [ ] 表示名（砂肝／軟骨入りセセリ／鶏足／鶏頭）をこの名前で出してよいか ※サイトの「選び方」と同じ名前にしている
- [ ] かたさ・香りの☆を、そのまま「作り手の実感」として載せてよいか
- [ ] 手羽先・砂肝・セセリの注意書きの言い方
- [ ] ネック2種（サイコロ／ロング）と鶏頭の扱い ※決まったら build.mjs の ITEMS を直して画像を作り直す
- 価格は画像に入れていない（商品カードに出るため。値上げのたびに画像を作り直さずに済む）

【画像】00_hero.png

「種類が多くて、どれを買えばいいか分からない」
そんな声をいただくことが増えたので、kukusini の淡路どりジャーキー全9種を「かたさ」と「香り」で比べてみました。

はじめての方は、いちばん人気の「ささみ」から試してみてください。

【見出し】かたさと香りで見る、全9種

【画像】01_map.png

【見出し】迷ったら、まずは「ささみ」

【画像】10_sasami.png

手でさくっと割れるやわらかさと、鶏の香りの強さが特徴です。
おやつにも、フードのトッピングにも。水でふやかせば、シニアの子にもあげやすくなります。

「ほかのおやつは食べないのに、これだけは食べる」という声をいちばん多くいただいている商品です。

【商品】ささみ

【見出し】やわらかめ｜はじめての子・シニアの子に

【画像】11_mune.png
ささみほど香りは強くありませんが、脂があるぶん甘みがあります。ささみが合わない子にもおすすめです。

【商品】むね

【画像】12_kimo.png
手で簡単に割れるやわらかさ。香りは9種の中でいちばん強く、好きな子はとことんハマります。食いムラのある子に試してほしい商品です。
※好みがはっきり分かれます。はじめは少なめのサイズがおすすめです。

【商品】きも（レバー）

【画像】13_atama.png
見た目のインパクトはありますが、砕けやすく小型犬でも噛めます。噛むのが好きな子に。
※崩れやすいので、床が汚れにくい場所であげてください。

【商品】鶏頭

【見出し】噛みごたえ｜噛むのが好きな子に

【画像】14_zuri.png
いかの燻製のような香りで、皮ガムくらいの噛みごたえ。脂肪が少なく、ダイエット中の子にも。
「かたいものをあげたいけれど、歯が心配」という方に。
※丸のみに注意してください。

【商品】砂肝

【画像】15_neck.png
噛むとザクザクほどける食感。カルシウムを摂らせたい小型犬に。ささみだと飲みこんでしまう大型犬のしつけ用にも使われています。
※丸のみに注意してください。

【商品】軟骨入りセセリ

【画像】16_tebasaki.png
パリパリ食感の骨入りジャーキー。コラーゲンが豊富です。骨が好きな、体重5kg以上の子に。
※必ず手に持ったまま、奥歯で噛ませてください。噛む力が弱い子、骨に慣れていない子、消化が弱い子には向きません。

【商品】手羽先

【画像】17_momiji.png
取り扱いの中でいちばんかたいジャーキーです。噛みたい気持ちの強い大型犬に。

【商品】鶏足

【見出し】ごはんにかける｜食の細い子・水分補給に

【画像】18_furikake.png
ささみを粉末にしたふりかけです。フードにかけたり、水に溶かしたり。食が細くなったシニアの子に好評です。

【商品】ささみふりかけ

【見出し】全9種 比較早見表
