# 原稿と写真の受け渡し（11/25 打ち合わせ後）

11/25 の打ち合わせで全体の方向性が決まったので、ワイヤーフレームは役目を終えた。
ここからは **文章は先方がシートで直す／写真は先方がドライブに写真名で入れる** 形で進める。

| ファイル | 中身 |
|---|---|
| `dist/kukusini_原稿と写真.xlsx` | 先方に渡すシート（はじめに／文章／写真／商品説明） |
| `annotate.js` `annotate.css` | 見本ページに番号（文章）と写真名（写真）の札を付ける仕掛け |
| `extract.js` | 見本ページを開いて番号の一覧と写真の切り抜きを取り出す（Playwright） |
| `build.py` | 上の2つを使って、見本ページとシートを作る |

```bash
python3 wireframes/build.py   # テンプレートのプレビュー → 番号つき見本 → シート の順に全部作る
```

- 見本ページ：`wireframes/dist/genko/`（Netlify の資料サイトでは `/genko/top.html` など）
- 写真の入れ先：Googleドライブ「2.写真・素材 ＞ サイト利用写真」
  https://drive.google.com/drive/folders/1mRrALdkIbxI-oWh8CbwaYqy15fQ4VOr4

## 番号と写真名の決まり

| 頭 | 場所 |
|---|---|
| C | 全ページ共通（メニュー・フッター） |
| T | トップ |
| A | About |
| S | 商品ページ（全商品共通の部分） |
| Q | お問い合わせ |
| P | 商品ごとの説明（シート「商品説明」だけ） |

写真名は「ページ_場所＋番号」（例：`トップ_メイン1` `about_つくり方2` `商品_つくり方バナー1` `共通_ロゴ`）。
商品写真は `商品_ささみ_1` のように商品名と枚数。

## 注意

- 番号は見本ページ上の並び順で振っている。**シートを渡したあとはテンプレートの文章を足したり消したりしない**（番号がずれる）。
  戻ってきたシートを反映するときに、まとめて直す。
- 商品名・価格・商品ごとの説明は BASE の管理画面で入れる部分なので、見本ページには番号を付けず、シート「商品説明」で受け取る。
- 管理画面の「ショップ紹介」（About の「お買い物について」に出る文章）とブログのお知らせも、番号の対象外。
